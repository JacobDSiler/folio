# Video 1 — "Write a book and share it in 15 minutes"

**Target length:** 5–7 minutes.
**Audience:** A brand-new user who's never seen Folio. Could be any genre, any skill level.
**Primary purpose:** Hero asset for the homepage, Twitter/X demos, Reddit embeds, and the top of the `/help/tutorials/` page.
**Secondary purpose:** The "what is Folio?" answer for the next year.

---

## Pre-production notes for the videographer

**Brand palette** (match callouts to these):
- Amber: `#c98c2a`
- Deep green: `#065f46`
- Cream background: `#f6f4ee`
- Serif typeface in the UI: Playfair Display
- Sans typeface in the UI: system sans

**Account to use:** Jacob will comp an Imprint-tier account before filming. Do NOT use a brand-new Google account on first record — Imprint tier unlocks the custom-subdomain field + press-photo library, which the follow-up videos need. For this video it doesn't matter, but keep the same account across the series for consistency.

**Browser:** Chrome at 1280×720 (standard HD, legible UI at reasonable zoom). Clear the bookmarks bar for clean framing. Hide any browser-extension chrome.

**UI zoom:** The default app layout fills the viewport at 100%. For callouts on small UI elements (chapter list, tab bar, status pills), zoom in to roughly 160% of the clicked area for 1.5–2 seconds, then zoom back out.

**Cursor:** Soft highlight ring around the cursor during active clicks. No annoying click-sound-effects unless Jacob approves.

---

## UX findings from the pilot (RESOLVED 2026-10-12)

Two findings worth noting; the toolbar one is now fixed:

1. **Toolbar now has `🔖 Release` + `📄 Print` as separate buttons.** (Was a single ambiguous `📦 Publish` that opened POD; shipped the split 2026-10-12.) The hero shot now uses the top-right `🔖 Release` as the primary click, no detour through the Ship tab required to reach the release panel.

2. **Default demo content "The Midnight Garden" by Eleanor Ashford** is beautiful and well-chosen. The script leverages it in the opening — *"You start with a short sample so you can see how everything looks before you paste your own in."*

3. **"You're browsing as a guest"** prompt is tasteful. Google sign-in is step 3 in the script so new users don't hit a permission denial mid-publish.

**Screen:** Click the **Ship** tab in the sidebar. The sign-in prompt is visible.
