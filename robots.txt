# Folio — robots.txt
# ═══════════════════════════════════════════════════════════════════
# Two-layer policy:
#
#   (1) Search engines (Google, Bing, DuckDuckGo, etc.) are ALLOWED
#       to crawl the public discovery surface — the welcome page,
#       the Shelf, imprint pages, and marketing pages. Blocked from
#       /admin/, /s/ (signed teaser links, ephemeral), and per-folio
#       reader URLs (author intent: your work isn't a search result
#       preview, it's meant to be read on Folio).
#
#   (2) AI TRAINING BOTS are DENIED across the entire site. Authors'
#       creative work should not become training corpus for models
#       they didn't consent to. This is the primary defence — well-
#       behaved bots respect these directives. Bad actors ignore them,
#       so we also layer:
#
#         - _headers file → X-Robots-Tag: noai, noimageai on
#           reader + imprint paths (secondary signal for crawlers
#           that check headers instead of robots.txt)
#         - Cloudflare dashboard → Bot Fight Mode + AI Bot Blocking
#           (paid enforcement for the disrespectful subset)
#
# Keep synced with docs/BOT_BLOCKING.md when adding a new bot.
# Added 2026-08-11 (Jacob's request).
# ═══════════════════════════════════════════════════════════════════
